Facility QR codes

Print one QR code per entrance. Scanning it opens that facility's Quick Parking page.

How to test the QR codes

  1. Scan a code with your phone camera, or open the printed link in a browser.
  2. On this computer: the generated address uses {{ base_url }}. It works in a browser on this machine.
  3. On a phone: a QR code pointing at localhost will not open. Set BASE_URL in your .env to this computer's network address (for example http://192.168.1.5:5000), restart the app, then regenerate the QR codes here and scan again. Both devices must be on the same Wi-Fi network.

Each code contains only the public address /parking/facility/<id> — never the administrator dashboard.
